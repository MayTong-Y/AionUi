# P5 收尾设计

先迁移 UI 图标，再清理已替代的视觉样式。与 P0 / tokens.md 冲突的旧颜色改为 CDS 语义变量；用户自定义字体和主题变量保持优先级。

涉及 IconPark 的 props 不只是图形名称：size、fill、theme、旋转、事件及 ref 需保留对应行为。仅作有明确 lucide 对应的迁移；没有对应或有品牌/语义要求的项目如实记录，不能用任意图标代替。

Arco 的表单校验、组合输入、Select、Modal、Table、Tree、虚拟列表等不是纯外观，迁移时须保留行为。共享外观通过明确的 CDS 兼容样式覆盖，P5 记录保留清单；未完成移除的依赖不能假称完成。
