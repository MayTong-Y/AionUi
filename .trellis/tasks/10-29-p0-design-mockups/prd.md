# P0 Claude 风格设计稿

父任务：`10-29-claude-ui-rewrite`

## 目标

在写代码之前，用 claude-design skill 产出一套可在本地画布编辑器里查看和修改的设计稿，确定新界面的视觉方向和主要页面的布局，作为 P1–P4 的实现依据。

## 输入

- open-claude-ui 的令牌与组件规范：表面阶梯、陶土橙品牌色、圆角矩阵、发丝边框、阴影、字体排版、动效时长。
- AionUI 现有的页面与功能清单（路由见 `packages/desktop/src/renderer/components/layout/Router.tsx`）。设计稿必须为现有功能留出位置，不能只画 Claude 本身有的东西。

## 要求

- 画板（每张都有明、暗两版）：
  1. 欢迎页（`/guid`）：问候语、大输入框、Agent / 助手选择入口、最近项目或快捷入口。
  2. 对话页（`/conversation/:id`）：侧栏、标题栏、消息流（用户气泡、助手正文、思考折叠、工具调用卡片、代码块）、输入框（附件胶囊、模型或 Agent 切换、发送和停止按钮）。
  3. 对话页加右侧预览或工作区分栏：文件预览、文件浏览器、源码管理。
  4. 侧栏展开和收起两种状态：新对话、会话分组历史、团队、定时任务入口、底部用户与设置。
  5. 设置页（以 Agent 设置为代表）：左侧分类导航和右侧表单。
  6. 团队页（`/team/:id`）的布局草图。
- 标题栏按 Windows 11 绘制（右上角最小化、最大化、关闭按钮）。
- 文字使用中文。
- 设计稿里的令牌数值（颜色、圆角、间距、字号）要与 open-claude-ui 的 `cds-theme.css` 一致，或在设计稿中注明偏离的地方，供 P1 直接使用。
- 不使用 Claude 的 logo 和名称；品牌位置使用 AionUI 的名称和 logo。

## 存放位置

`docs/design/claude-ui/`（随仓库提交）。

## 验收标准

- [x] 上述 6 组画板都已完成明暗两版，能在本地画布编辑器中打开。
- [x] 用户确认视觉方向，或明确列出需要修改的地方。
- [x] 整理一份令牌摘要（颜色、圆角、阴影、字体、间距），作为 P1 的输入。

## 不在范围内

- 写任何 renderer 代码。
- 移动端布局。现有 WebUI 的移动端适配在 P2 或 P4 中处理，P0 只画桌面宽度。
