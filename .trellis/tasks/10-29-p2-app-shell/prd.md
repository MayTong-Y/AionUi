# P2 应用外壳

## 目标

将 P0 已确认的侧栏、标题栏视觉接入现有应用外壳，复用 P1 CDS，保持现有路由、拖拽排序、预览分栏、桌面与移动端行为。

## 要求

- 桌面侧栏默认 260px，收起保留 56px 图标栏；宽度使用 CSS 变量，保留现有手动调宽、吸附收起和宽度记忆。
- 侧栏使用 CDS 表面、32px 导航项、lucide 图标和 AionUI 品牌；现有历史、助手、搜索、定时任务、团队与设置入口可用。
- 桌面标题栏统一 40px，复用窗口最小化/最大化/还原/关闭桥接；保留 WebUI 隐藏窗口按钮、macOS 原生按钮和移动端分支。
- 新外壳接入 CdsProvider；路由 Outlet、LayoutContext、预览与工作区逻辑保留。
- 只改外壳视图，不重写对话、设置、团队内容页，不修改数据 hooks、IPC 协议或正式安装版。

## 验收

- [x] 展开/收起布局与设计令牌一致，收起时仍有可用导航入口（组件预览与定向测试）。
- [x] 标题栏外观与窗口行为兼容现有平台分支（视图及桥接测试；原生平台实测见验证边界）。
- [ ] 预览、工作区、移动端遮罩与路由容器保持原有行为。
- [x] 改动文件格式/lint、类型检查与相关定向测试通过。
- [x] 完成最小外壳运行检查，或明确记录无法实测的边界；不宣称未经执行的全站验收。

## 执行约定

2026-10-30 用户授权 GPT-6-sol 子代理推进。沿用现有画板；必要时可用 baoyu-design 与编辑器继续设计，可参考 open-claude-ui。遵循此前要求，不全量检查画板或运行大量全量验证；不提交、不推送。
