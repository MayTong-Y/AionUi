简单说，AionUI 是一个桌面版的 AI 助手外壳：它本身不训练模型，而是把 Claude Code、Codex、Gemini CLI 这些命令行 Agent 装进一个统一的图形界面里，让你像聊天一样指挥它们读写你电脑上的文件。

项目分三层，入手顺序建议如下：

  1. 主进程 src/process/：启动窗口、管理 Agent 进程。
  2. 渲染进程 src/renderer/：你看到的所有界面。
  3. IPC 桥 src/preload/：前两者之间唯一的通信通道。
